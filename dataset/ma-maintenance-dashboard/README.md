# MA Flow 維護合約管理台

依據 `2027MA維護保固合約統計.pdf` 的追蹤邏輯設計，將「已報價」與「即將到期、需報價」轉為可操作的網頁工作流程。

## 功能

- 首頁顯示待報價、待回簽件數與完成度
- 點擊首頁數字或卡片可查看對應明細
- 支援關鍵字、狀態、到期月份篩選
- 可新增與編輯 MA 合約資料
- 以紅字標示待報價契約，以黃色標籤標示已建立報價單號
- 資料自動保存在瀏覽器 `localStorage`
- 可匯出 UTF-8 CSV 供 Excel 使用
- 響應式桌面、平板與手機版面

## 使用方式

直接開啟 `index.html`，或在此資料夾啟動任一靜態網站伺服器：

```bash
npx serve .
```

> 公開版僅使用匿名示範資料，不包含來源 PDF 的真實客戶名稱、金額或報價單號。正式資料可在網頁中新增，並只會保存在使用者自己的瀏覽器。
